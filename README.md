# CBT Registration Checker

A simple Android app where each student checks their *own* registration status on the UNI UYO CBT portal.

## What it does

1. Student enters their own registration number
2. App opens the CBT portal in the browser
3. Student completes the check manually (tick box, submit)
4. Student comes back and taps Share to report their status to the class rep

## What it does NOT do

- No bulk enumeration of registration numbers
- No automated form submission
- No CAPTCHA solving or bypassing
- No data collection from other students

## Building

The APK is built automatically via GitHub Actions on push to main.
Download the artifact from the Actions tab.
